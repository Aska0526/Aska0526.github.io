# Fanchao — Personal Bio

A responsive, single-page personal site for GitHub Pages. It uses plain HTML, CSS, and a tiny JavaScript enhancement; there is no build step or dependency installation.

## Preview locally

Open `index.html` in a browser, or serve the folder with any static file server.

## Publish at `Aska0526.github.io`

1. Create a public GitHub repository named exactly `Aska0526.github.io`.
2. Add these files to the repository root and push them to the `main` branch.
3. In the repository, open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. GitHub Pages will publish the site at `https://Aska0526.github.io` after deployment completes.

The site currently links to the GitHub account and project supplied in the brief. No email address or other contact details were provided, so the Contact section points to GitHub.
