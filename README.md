# Chao Fan — personal bio

A responsive, single-page personal site for GitHub Pages. It uses plain HTML, CSS, and a small JavaScript enhancement; there is no build step or dependency installation.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish at `Aska0526.github.io`

1. Keep the site files in the root of the public `Aska0526.github.io` repository.
2. Push changes to the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)` if Pages is not already configured.
4. GitHub Pages publishes the site at <https://aska0526.github.io/> after deployment.

The portrait currently uses the signed image URL from Chao's LinkedIn profile. LinkedIn may expire that URL; if the portrait stops loading, save a fresh profile photo as a local asset and update the `<img>` in `index.html`.
